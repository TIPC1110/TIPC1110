### 👨‍💻 Về Tôi / About Me

Mình là một **Full Stack Developer** đam mê công nghệ tại Việt Nam, sáng lập và phát triển hệ sinh thái **`ctdoteam`**. Mình tập trung xây dựng các ứng dụng web hiệu năng cao, tiện ích desktop (macOS & đa nền tảng), và tích hợp các giải pháp AI thiết thực vào cuộc sống.

- 🔭 **Dự án trọng tâm đang phát triển:** 
  - **[CTDOBus (ctdomap)](https://github.com/TIPC1110/ctdomap)**: Hệ thống điều hành & bản đồ xe buýt Hà Nội trực tiếp thời gian thực (Live GPS telemetry, SSE streaming, thuật toán tìm tuyến thông minh BFS).
  - **[ctdoshot](https://github.com/TIPC1110/ctdoshot)**: Ứng dụng menu-bar chụp & xử lý ảnh màn hình native trên macOS viết bằng Swift 5.9.
  - **[LUCA OS](https://github.com/TIPC1110/luca-os)**: Hệ thống AI Agentic đa mô hình tích hợp Second Brain.
- 🌱 **Đang tìm hiểu & trau dồi sâu:** High-performance systems với **Rust**, native desktop apps với **Swift**, và kiến trúc **AI Agents / LLM Orchestration**.
- 💬 **Thế mạnh:** Full-stack development (TypeScript/React/Node.js/Hono), Real-time data streaming (SSE, WebSockets), REST APIs, Supabase & Cloud tools.
- ⚡ **Phương châm:** *"Code is poetry, and every commit tells a story."* Viết mã nguồn sạch, tối ưu và mang lại giá trị thực tế.
